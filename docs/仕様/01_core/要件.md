# 要件

## プロジェクト概要
**LivingGlass** は、リビングルーム等に設置された常時表示モニター（ミニPC接続）上で、設定ファイルに定義した任意のWebページ/Webアプリ（最大3つ）を画面分割で統合表示し、画面の焼き付き防止と自動更新を行う汎用スマートダッシュボードシステムです。

## 機能要件
- **FR-01: 可変画面分割表示 (1〜3画面動的レイアウト)**
  - 外部設定ファイルで指定されたURLの数（最大3つ）に応じて、画面を自動的に動的分割（1枠: 100%、2枠: 50%/50%、3枠: 33.3%×3）すること。
  - 設定されたURLの数にぴったり合わせて分割し、URLが2つの場合に3分割枠（空き枠）が発生する状態を回避すること。
  - 外枠やスクロールバーを非表示にし、シームレスなスマートディスプレイUIを提供すること。
- **FR-02: 外部設定ファイルによるカスタマイズ (Config Driven)**
  - 表示対象のURL（最大3つ）、更新間隔、ピクセルシフト間隔などをソースコードを修正せずに外部設定ファイル（`config.js` 等）から変更可能であること。
- **FR-03: Webページのサイレント自動更新 (Auto Refresh)**
  - 設定された間隔（例: 15分ごと）で、設定されているすべてのWebページをバックグラウンドで自動再読み込み（リロード）すること。
- **FR-04: アプリ層 画面焼き付き防止機能 (Burn-in Prevention)**
  - 一定時間ごと（例: 5分ごと）に全要素の位置を数ピクセル単位でランダム移動（ピクセルシフト）させること。
  - 定期更新時に画面全体のフェードアウト/フェードイン（暗転リフレッシュ）を行い、液晶素子の固定表示状態を全画素まとめてリセットすること。
- **FR-05: 自動フルスクリーン起動 (Kiosk Mode)**
  - ミニPC起動時にブラウザのキオスクモード等で自動全画面起動すること。
- **FR-06: スクリプトによる1コマンドセットアップ ＆ 初回起動 (Scripted Setup & Launch)**
  - `app` フォルダをコピーして `config.js` にURLを格納後、単一のスクリプトファイル（`setup.sh` または `setup.ps1`）を実行するだけで、必要な自動起動設定や画面電源タイマー登録が完了し、即座にダッシュボードが初回起動すること。

## 非機能要件
- **NFR-01: OSS・パブリックリポジトリ向け汎用性**
  - 特定のWebサービスや個人環境に依存したハードコーディングを排除し、設定ファイルのみで任意のWebサイトをマルチ表示できる汎用設計とすること。
- **NFR-02: 稼働安定性・リソース解放**
  - 定期的なリロードにより、ブラウザの長時間の稼働に伴うメモリリーク（メモリ肥大化）を防ぎ、365日無人連続稼働に耐えうること。
- **NFR-03: 静音性・省電力性**
  - 夜間帯の自動ディスプレイ消灯と連動し、不要な電力消費および発熱を最小限に抑えること。

## 制約事項
- **CST-01: ハードウェア構成**
  - AC電源供給のPC/ミニPC ＋ 常時表示モニター 構成を前提とする。
- **CST-02: 分割数上限**
  - 同時表示できるURL数は最大3つまでとし、視認性とリソース消費の最適化を図る。
