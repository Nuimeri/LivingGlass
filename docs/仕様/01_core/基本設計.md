# 基本設計

## 概要
`LivingGlass` は、`app` フォルダをコピーして `config.js` にURL（最大3つ）を記述後、セットアップスクリプトを1回実行するだけで、常時表示モニター上にマルチWebページを可変分割表示し、画面の焼き付き防止および自動更新を開始する汎用スマートダッシュボードシステムです。

## 導入＆運用ワークフロー

```
[1. 準備] app フォルダを任意のディレクトリへコピー
   ↓
[2. 設定] config.js に表示したいURL（最大3つ）を格納
   ↓
[3. 実行] setup.ps1 (Windows) または setup.sh (Linux) を実行
   ↓
[自動処理] ブラウザがキオスク起動 ＋ OSスタートアップ・夜間電源タイマーの自動登録完了！
```

## システムアーキテクチャ

```
[ 導入端末 (ミニPC / PC) ]
  ├── 起動スクリプト (setup.ps1 / setup.sh)
  │    ├── ① OSスタートアップ / cron 自動登録
  │    └── ② ブラウザ (キオスクモード) 初回立ち上げ
  │
  ├── OSレベル制御 (タスクスケジューラ / cron)
  │    └── 夜間帯 (23:00~06:00) : DPMS / モニター電源 OFF / ON 制御
  │
  └── ブラウザ (Google Chrome / Edge - キオスクモード)
       ├── 外部設定ファイル (app/config.js) ─── [ 最大3つのURL設定 ]
       └── LivingGlass ダッシュボード (app/index.html)
            ├── CSS Grid 動的レイアウト (設定URL数 N に応じて repeat(N, 1fr) で最適分割)
            ├── ピクセルシフト・暗転フェードモジュール (JavaScript)
            ├── <iframe> #1 ───> ターゲットWebページ #1
            ├── <iframe> #2 ───> ターゲットWebページ #2 (設定時)
            └── <iframe> #3 ───> ターゲットWebページ #3 (設定時)
```


## 機能一覧
| 機能名 | 概要 | 担当層 |
| :--- | :--- | :--- |
| **動的画面分割表示** | 設定ファイル内のURL数（1〜3個）に合わせて `grid-template-columns` を自動生成し画面を最適分割 | JavaScript / CSS (Grid) |
| **設定ファイルの外部化** | ソースコードを変更せずURL・更新周期・シフト間隔を変更可能 | JavaScript (`config.js`) |
| **画面定期自動更新** | 設定時間ごとに全 `iframe.src` を再割り当てしバックグラウンドリロード | JavaScript (setInterval) |
| **ピクセルシフト** | 5分ごとに全画面の位置を `±2px` ランダム移動 | JavaScript (CSS Transform) |
| **全画面素子リフレッシュ** | 更新時に全画面を1〜2秒間暗転（黒フェード）させて残像リセット | JavaScript + CSS Overlay |
| **夜間自動消灯/復帰** | 深夜帯の画面表示オフによる焼き付き完全回避と省エネ | OS (PowerShell / cron) |

## 画面設計
- **可変分割ルール**:
  - 設定URL 1つの場合：100% 全画面表示
  - 設定URL 2つの場合：50% / 50% 左右2分割
  - 設定URL 3つの場合：33.3% × 3 左右3分割（上限3画面）
- **空き枠の防止**: URLが2つの場合、決して3分割枠を作らず、登録数に完全にフィットしたグリッド幅を自動適用。
- **枠線・余白の撤廃**: `border: none; overflow: hidden;` により枠線を完全に除去。

## 焼き付き防止・省エネ運用設計
1. **昼間（稼働時間 06:00 〜 23:00）**
   - 5分間隔：ピクセルシフト（素子固定化防止）
   - 15分間隔：暗転フェード ＋ 全ターゲットページ同時リロード（メモリ解放 ＋ 全画素リフレッシュ）
2. **夜間（就寝時間 23:00 〜 06:00）**
   - OSのディスプレイ管理コマンドにより、モニターへの出力信号を停止（スリープ移行）。朝6時に信号再開。
