## セットアップ＆起動スクリプト設計 (`setup.ps1` / `setup.sh`)

スクリプトを実行すると、以下の処理が完全自動で実行されます。

1. **環境チェック**: `config.js` および `index.html` の存在確認。
2. **自動起動登録**: 
   - Windows: ショートカットを作成し、スタートアップフォルダ (`shell:startup`) へ配置。
   - Linux: `~/.config/autostart/livingglass.desktop` を生成。
3. **ディスプレイ消灯タイマー登録** (オプション/選択): 23:00 消灯、06:00 復帰のタスク/cron を自動設定。
4. **初回即時起動**: Chrome / Edge を `--kiosk --app="file:///path/to/app/index.html"` オプションで即座にフルスクリーン起動。


## 設定ファイル仕様 (`config.js`)

ユーザーは `config.js` に最大3つのURLを設定できます。

```javascript
window.LIVING_GLASS_CONFIG = {
  // 表示対象のWebページURL（最大3つまで設定可能）
  urls: [
    "https://example.com/dashboard-1",
    "https://example.com/dashboard-2",
    // "https://example.com/dashboard-3" // 最大3つまで追加可能
  ],
  shiftIntervalMs: 5 * 60 * 1000,    // ピクセルシフト間隔 (ミリ秒)
  refreshIntervalMs: 15 * 60 * 1000  // 全画面リフレッシュ間隔 (ミリ秒)
};
```

## UIレイアウトおよび動的生成ロジック (HTML / CSS / JS)

### 1. 動的CSS Grid配置
設定されたURL数 `N = urls.length` （最大3）に基づき、JavaScriptから `grid-template-columns: repeat(N, 1fr)` を動的設定します。

```css
body, html {
  width: 100vw;
  height: 100vh;
  margin: 0;
  padding: 0;
  overflow: hidden;
  background-color: #000000;
}

#dashboard-container {
  display: grid;
  /* JavaScriptにて repeat(urls.length, 1fr) を適用 */
  width: 100%;
  height: 100%;
  transition: transform 0.5s ease-out;
}

iframe {
  width: 100%;
  height: 100%;
  border: none;
}

#refresh-overlay {
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  background-color: #000000;
  opacity: 0;
  pointer-events: none;
  transition: opacity 1s ease-in-out;
  z-index: 9999;
}
#refresh-overlay.active {
  opacity: 1;
}
```

### 2. 動的DOM生成スクリプト (`index.html` 内 JS)

```javascript
const config = window.LIVING_GLASS_CONFIG || { urls: [] };
const container = document.getElementById('dashboard-container');
const overlay = document.getElementById('refresh-overlay');

// 上限3つまでに制限
const targetUrls = (config.urls || []).slice(0, 3);
const iframes = [];

// ① 登録URL数に応じてグリッドとiframeを動的生成 (余分な分割枠を作らない)
container.style.gridTemplateColumns = `repeat(${targetUrls.length}, 1fr)`;

targetUrls.forEach((url, index) => {
  const iframe = document.createElement('iframe');
  iframe.id = `frame-${index}`;
  iframe.src = url;
  container.appendChild(iframe);
  iframes.push(iframe);
});

// ② ピクセルシフト処理 (-2px ~ +2px)
setInterval(() => {
  const dx = Math.floor(Math.random() * 5) - 2;
  const dy = Math.floor(Math.random() * 5) - 2;
  container.style.transform = `translate(${dx}px, ${dy}px)`;
}, config.shiftIntervalMs || 300000);

// ③ 暗転リフレッシュ ＋ 全iframe一括再読み込み
setInterval(() => {
  overlay.classList.add('active');

  setTimeout(() => {
    iframes.forEach((iframe, i) => {
      iframe.src = targetUrls[i];
    });
  }, 1000);

  setTimeout(() => {
    overlay.classList.remove('active');
  }, 2200);
}, config.refreshIntervalMs || 900000);
```

## OSタイマー制御設計 (夜間消灯・早朝復帰)

### Windows の場合 (タスクスケジューラ + nircmd)
- **消灯タスク (毎日 23:00)**: `nircmd.exe monitor async off`
- **復帰タスク (毎日 06:00)**: `nircmd.exe sendkey shift press`

### Linux (Ubuntu等) の場合 (cron)
- **消灯タスク (毎日 23:00)**: `0 23 * * * DISPLAY=:0 xset dpms force off`
- **復帰タスク (毎日 06:00)**: `0 6 * * * DISPLAY=:0 xset dpms force on`

## テスト観点
1. **動的分割数検証**: 
   - URLが1つの場合: 100%単一表示になること。
   - URLが2つの場合: 50%:50%の2分割になり、3分割用の空き領域が発生しないこと。
   - URLが3つの場合: 33.3%の3分割になること。
   - URLが4つ以上指定された場合: 上限3つまででカットオフされること。
2. **iframe更新検証**: リロード時に全iframeが正しく背景更新されること。
3. **ピクセルシフト動作検証**: 5分ごとに位置移動が行われること。
