# 導入手順

## 前提条件
- PC / ミニPC（Windows 11 または Linux/Ubuntu等）
- 常時表示用モニター（HDMI / USB Type-C 接続）
- 表示対象のWebサイト/Webアプリ（最大3つ）がアクセス可能であること。
- Google Chrome または Microsoft Edge がインストールされていること。

## 超シンプル 3ステップ導入手順

### ステップ 1: `app` フォルダのコピー
リポジトリ内の `app` フォルダを、導入先PCの任意のディレクトリ（例: `C:\LivingGlass\app` または `~/LivingGlass/app`）にコピーします。

### ステップ 2: 設定ファイル (`config.js`) の編集
`app/config.js` をテキストエディタで開き、表示したいWebページのURLを最大3つ記述します。

```javascript
window.LIVING_GLASS_CONFIG = {
  // 表示したいURL（1〜3個まで）
  urls: [
    "http://localhost:3000/dashboard-a",
    "http://localhost:4000/dashboard-b"
  ],
  shiftIntervalMs: 5 * 60 * 1000,    // ピクセルシフト (5分)
  refreshIntervalMs: 15 * 60 * 1000  // 暗転リフレッシュ (15分)
};
```

### ステップ 3: セットアップスクリプトの実行

**Windows の場合**:
`app/scripts/setup.ps1` を右クリックして「PowerShell で実行」します（またはコマンドプロンプト/PowerShellから実行）。
> ※ 自動的にOSスタートアップ登録、画面制御タイマー設定が行われ、ブラウザがキオスクモードで初回起動します。

**Linux (Ubuntu) の場合**:
ターミナルを開き、スクリプトを実行します：
```bash
cd ~/LivingGlass/app/scripts
chmod +x setup.sh
./setup.sh
```


---

## 動作確認
1. スクリプト実行後、Chromeがキオスクモード（フルスクリーン）で即座に立ち上がり、`config.js` に指定したURL数にぴったり合わせて画面が分割（1枠〜3枠）表示されることを確認します。
2. 5分経過時にピクセルシフト、15分経過時に画面暗転リフレッシュが動作することを確認します。
3. PC再起動時にダッシュボードが自動立ち上げされることを確認します。


## 注意事項
- 外部Webサイトを表示する場合、サイト側で `X-Frame-Options: DENY` または `SAMEORIGIN` が設定されていると `iframe` 埋め込みがブロックされる場合があります。その場合はご自身のWebサーバー等でプロキシ・ヘッダー調整を行うか、埋め込み許可されたWebページをご指定ください。
